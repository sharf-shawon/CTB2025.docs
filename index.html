    CTB Admin Documentation¶

    CTB Admin documentation helps you run day-to-day business operations in one place. Use this site to learn workflows, complete tasks faster, and understand where each function lives in the system.

    Start here¶

    1. Open the Getting Started Overview to understand the interface and module layout.
    2. Read Login and Logout if you are setting up a new user or device.

    3. Review the Dashboard guide to understand key metrics and quick access cards.

    4. Getting Started Overview

    5. Login and Logout
    6. Dashboard

    How this documentation is organized¶

    The User Guide is grouped by business function. Choose the section that matches your work.

    Business¶

    Manage clients and vendors, including onboarding, profile updates, and account-level details.

    • Business Module Overview
    • Clients Overview
    • Vendors Overview

    Factory¶

    Manage categories, materials, inventory, and products used for production workflows.

    • Factory Module Overview
    • Categories Overview
    • Products Overview

    Trade¶

    Handle invoicing, payments, checks, vouchers, and banking records.

    • Trade Module Overview
    • Invoices Overview
    • Payments Overview

    Employee¶

    Manage employees, attendance, salary, wages, payouts, and tasks.

    • Employee Module Overview
    • Employees Overview
    • Salary Overview

    Settings and Admin¶

    Control users, audit logs, app settings, SMS notifications, and maintenance options.

    • Settings and Admin Overview
    • User Management
    • Audit Log

    Reference¶

    Find shared definitions, common error references, and offline-mode behavior.

    • Glossary
    • Error Pages
    • Offline Mode

    Common tasks¶

    • Onboard a new client: Add Client
    • Create a new invoice: Create Invoice
    • Record staff attendance: Record Attendance
    • Generate payroll records: Generate Salary

    Navigation tips¶

    • Use the left sidebar to jump directly to a module.
    • Open module Overview pages first to understand available sub-pages.
    • Use your browser search on long pages to find field names quickly.
