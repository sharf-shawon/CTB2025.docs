# CTB Admin Documentation

CTB Admin documentation helps you run day-to-day business operations in one place. Use this site to learn workflows, complete tasks faster, and understand where each function lives in the system.

## Start here

1. Open the **Getting Started Overview** to understand the interface and module layout.
1. Read **Login and Logout** if you are setting up a new user or device.
1. Review the **Dashboard** guide to understand key metrics and quick access cards.

- [Getting Started Overview](user-guide/00-getting-started/overview.md)
- [Login and Logout](user-guide/00-getting-started/login-and-logout.md)
- [Dashboard](user-guide/00-getting-started/dashboard.md)
