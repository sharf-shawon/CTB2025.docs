# Browse by tag

Every page in the User Guide carries tags for the module it belongs to, the kind
of task it covers, and the role that normally performs it. Use this page to find
work across modules — for example, everything an accountant does, or every page
that explains how to create a record.

## How tags are structured

| Namespace  | Meaning                               | Values                                                                                                                     |
| ---------- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **module** | The part of CTB Admin the page covers | `getting-started`, `business`, `factory`, `trade`, `employee`, `returns`, `commission`, `reports`, `settings`, `reference` |
| **task**   | What you are trying to do             | `create`, `edit`, `view`, `report`, `configure`, `troubleshoot`                                                            |
| **role**   | Who usually does this work            | `staff`, `accountant`, `hr`, `admin`                                                                                       |

A page tagged `module:trade`, `task:create`, `role:accountant` explains how an
accountant creates a record in the Trade module.

!!! tip "Searching instead"

    Tags are best for browsing a whole category. To find a specific field name or
    message, use the search box at the top of any page.
