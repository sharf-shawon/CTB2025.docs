# Add or Edit Department

Use this page to create a new department or update an existing one.

## Summary

This form keeps department naming and status information in one place. Use it when the organization changes structure or when you need to correct an existing department record.

## When to use this page

- When a new department needs to be added.
- When a department name needs to be corrected.
- When you want to mark a department active or inactive.

## How to access this page

From the sidebar, go to **Employee -> Departments** and choose add or edit on a record.

## Step-by-step instructions

1. Open **Departments Overview** from the sidebar.
1. Click the add action or open an existing department.
1. Enter or update the department name and description.
1. Set the status if your workflow uses active/inactive control.
1. Save the record.

## Field reference

- **Department name** - The name employees will be grouped under.
- **Description** - Optional explanation of the department's purpose.
- **Status** - Controls whether the department is available for new records.

## Tips and common issues

- Use names that match how the business talks about departments internally.
- Mark a department inactive if old records still need to keep the history.
- Review employee assignments before changing a department name.
