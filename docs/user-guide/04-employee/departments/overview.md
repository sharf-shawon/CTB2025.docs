# Departments Overview

Use this page to review the departments used in employee records and keep department names consistent across the system.

## Summary

Departments help organize employees for reporting, payroll, and task assignment. Use this list to confirm the available departments before you add or edit employees.

## When to use this page

- When you want to review existing departments.
- When you need to confirm a department name before assigning staff.
- When you want to open the create or edit page.

## How to access this page

From the sidebar, go to **Employee -> Departments**.

## Step-by-step instructions

1. Open **Departments Overview** from the sidebar.
1. Review the department list.
1. Open a department to edit it or create a new one if it does not exist.

## Field reference

- **Department name** - The label used to group employees.
- **Description** - Optional notes about the department's role.
- **Status** - Shows whether the department is active.

## Tips and common issues

- Keep department names short and consistent.
- Do not rename departments casually if they are already used in employee records.
- Mark old departments inactive instead of deleting them when history matters.
