# Add or Edit Position

Use this page to create a new job position or update an existing one.

## Summary

The position form keeps role names and status values consistent across employee records. Use it when the business creates a new role or when an old title needs correction.

## When to use this page

- When you need to add a new position.
- When a position title should be updated.
- When you want to mark a position active or inactive.

## How to access this page

From the sidebar, go to **Employee -> Positions** and choose add or edit on a record.

## Step-by-step instructions

1. Open **Positions Overview** from the sidebar.
1. Click the add action or open an existing position.
1. Enter or update the position title and description.
1. Set the status if your workflow uses active/inactive control.
1. Save the record.

## Field reference

- **Position title** - The job title used for the employee.
- **Description** - Optional explanation of the role.
- **Status** - Controls whether the position is available for new employee records.

## Tips and common issues

- Use a title that matches the wording used by HR and management.
- Mark old positions inactive instead of deleting them when history matters.
- Review assigned employees before changing a position title.
