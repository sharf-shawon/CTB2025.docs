# Employee Module

Use the Employee module to manage staff structure, attendance, salary, payouts, tasks, and purchase balances.

## Summary

The Employee section keeps the staffing side of CTB Admin organized. Use it to maintain departments and positions, record attendance, generate salary, issue payouts, and track assigned work.

## What you can do in this section

- Manage departments and positions.
- Add and update employee records.
- Review attendance and salary cycles.
- Issue employee payouts or advances.
- Track tasks and purchase balances.

## Module structure

| Module           | Purpose                                         |
| ---------------- | ----------------------------------------------- |
| Departments      | Group employees by department or team.          |
| Positions        | Store job titles used on employee records.      |
| Employees        | Maintain staff profiles and employment details. |
| Attendance       | Record and review attendance activity.          |
| Salary           | Generate and review monthly salary records.     |
| Wages            | Store wage-based compensation entries.          |
| Payouts          | Record advances or other employee payouts.      |
| Tasks            | Track work assigned to staff members.           |
| Purchase Balance | Review employee purchase-ledger balances.       |

## Typical workflow

1. Set up departments and positions.
1. Add or update employee records.
1. Record attendance.
1. Generate salary for the payroll month.
1. Create payouts or review purchase balances when needed.
