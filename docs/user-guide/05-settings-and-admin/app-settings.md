# App Settings

Use this page to update global CTB Admin behavior such as business defaults, operational toggles, and system-wide configuration values.

## Summary

Use this page when you need to adjust settings that affect all users. Changes here can impact workflows across multiple modules, so updates should be reviewed carefully.

## When to use this page

- When business rules or default values change.
- When system-wide behavior must be enabled or disabled.
- When administrators need to align settings with operational policy.

## How to access this page

From the left sidebar, go to **Settings and Admin -> App Settings**.

## Prerequisites

- You have permission to manage global settings.
- You have approval for system-wide configuration changes.

## Step-by-step instructions

1. Open **App Settings** from the sidebar.
1. Locate the setting group you need to update.
1. Change one setting at a time to reduce risk.
1. Click **Save** and verify expected behavior in affected modules.
1. Record the change in your team change log if your process requires it.

## Field reference

- **Setting name** - The configuration item being controlled.
- **Current value** - Active value currently applied in the system.
- **New value** - Updated value you want to apply.
- **Save** - Applies updated settings for all users.

## Tips and common issues

- Avoid changing multiple unrelated settings in one update.
- Validate key workflows right after saving critical settings.
- If behavior changes unexpectedly, review recent app-setting edits first.
