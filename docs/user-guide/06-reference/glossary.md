# Glossary

Use this page to look up the business terms used throughout CTB Admin documentation.

## Summary

The glossary helps staff read the docs and interface terms with the same meaning. Use it when a label or workflow term needs a quick business explanation.

## Terms

| Term             | Meaning                                                        |
| ---------------- | -------------------------------------------------------------- |
| Chalan           | A delivery document that lists goods without pricing.          |
| Voucher          | A financial record used for non-invoice transactions.          |
| Tender Invoice   | A proposal or tender-style invoice prepared before commitment. |
| Salary           | A staff member's monthly compensation record.                  |
| Payout           | An advance or other employee payment recorded in the system.   |
| Purchase Balance | An employee ledger that tracks purchase-related balances.      |

## When to use this page

- When you are unsure what a term in a workflow means.
- When you need a quick reference before training someone else.
- When you want to keep documentation wording consistent.
