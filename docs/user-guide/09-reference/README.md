# Reference

Shared definitions, error messages, permissions, and behaviour that apply across every module of CTB Admin.

## Summary

Use this section when a term, message, or restriction is not specific to one module. Reference pages are written once here and linked from the module pages that need them, so a definition never drifts between modules.

______________________________________________________________________

## What you can do in this module

- Look up a business term used across invoices, payments, salary, and reports.
- Identify an error page and find out what to do about it.
- Check which role can see or change a given area of the system.
- Understand what still works when your connection drops.
- Work through common problems before raising a support request.

## Typical workflow

1. Search for the term or message you are looking at.
1. Open the reference page the search returns.
1. Follow the link back to the module page that describes the task you were doing.
1. If the answer is not here, check the module's own **Tips and common issues** section.
